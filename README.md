# BusyRoad

**Дорога, которая меняется вместе с погодой за окном.** Пиксельная поездка от первого лица для BUSY Bar. Капли, снежинки и листья оседают на лобовом стекле. Нажми **Start**, чтобы сделать взмах дворником.

![Осенняя дорога на закате, кадр из BUSY Bar Emulator](screenshots/cover.png)

Проект создан для хакатона [BUSY JS Apps Contest](https://busy.app/pages/js-apps-contest).

## Как это работает

Передний экран **72 × 16** показывает дорогу, разметку и обочину в движении. На заднем экране **160 × 80** видны город, температура, время суток и шкала загрязнения стекла.

BusyRoad запрашивает текущую погоду по координатам выбранного города примерно каждые 10 минут. Рассвет, закат и ночь вычисляются по положению солнца. Ночью дорогу освещают фары и фонари. При грозе молния на мгновение подсвечивает небо, дорогу и обочину. [Данные погоды Open-Meteo](https://open-meteo.com/en/docs).

Летящие частицы движутся через кадр, а капли, снежинки, листья, пыль и следы мушек постепенно накапливаются на стекле. Дворник убирает их по мере взмаха. Снежинки остаются на стекле, даже когда снегопад закончился.

## Режимы и управление

- **LIVE** — погода и время суток выбранного города. При сбое сети можно увидеть последние сохранённые данные возрастом до трёх часов.
- **DEMO** — 14 сцен. В любой из них можно переключить день и ночь. Осенняя сцена также открывается на закате.

| Управление | Действие |
| --- | --- |
| **Start / Pause** | Сделать взмах дворником. |
| **Поворот колеса** | Выбрать демосцену. |
| **Удержание OK** | Переключить день и ночь в деморежиме. |
| **Короткое нажатие OK** | Вернуться к реальной погоде. |
| **Back** | Выйти из приложения. |

## Настройки

Открой **Apps → BusyRoad** в [локальном веб-интерфейсе эмулятора](http://127.0.0.1:8640/) или на странице своего BUSY Bar. После сохранения перезапусти приложение.

| Настройка | Что выбрать |
| --- | --- |
| **City and country** | Найди город и выбери результат с нужной страной. По умолчанию используется Сан-Франциско, США. |
| **Temperature units** | **Celsius** (°C, по умолчанию) или **Fahrenheit** (°F) для заднего дисплея. |
| **Wiper interval** | **Manual** (по умолчанию) или автоматический взмах каждые **5, 10, 20, 30 или 60 секунд**. Кнопка **Start** запускает взмах и заново отсчитывает интервал. |

Для поиска города веб-интерфейс использует сервис BUSY. Приложение передаёт координаты выбранного города в Open-Meteo для получения погоды.

## Сборка и запуск

Установи Node.js **22.12 или новее** и запусти [официальный BUSY Bar Emulator](https://github.com/busy-app/busybar-emulator).

```sh
npm ci
npm run build
npm run app:install -- --addr 127.0.0.1:8640
npm run app:run -- --addr 127.0.0.1:8640
```

После сборки в `dist/` появится пакет `app.busyroad.drive.tgz`. Его можно установить через веб-интерфейс устройства. В браузерной версии эмулятора дисплеи и кнопки доступны на [странице эмулятора](http://127.0.0.1:8640/emulator).
